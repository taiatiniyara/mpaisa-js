# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in mpaisa-js, please report it through [GitHub Security Advisories](https://github.com/taiatiniyara/mpaisa-js/security/advisories/new). **Do not open a public issue.**

You should receive a response within 72 hours. We will work with you to understand the issue and coordinate a fix and disclosure timeline.

## Scope

This policy covers the mpaisa-js npm package. It does not cover:

- The M-PAiSA Payments Gateway itself (report to Vodafone Fiji)
- Third-party dependencies (report to their maintainers)
- Integration issues in your application code

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x | Yes |
| < 0.1 | No |
